### Cause of Missing `bg-background`
The `.bg-background` class is entirely absent from the compiled CSS. 
The project has `tailwindcss@3.4.1` installed and uses an empty `tailwind.config.ts`. The `app/globals.css` imports `@import "shadcn/tailwind.css"`, but because `tailwind.config.ts` does not contain the `colors: { background: "var(--background)" }` extensions or a Shadcn preset plugin required by Tailwind v3 to resolve `bg-background`, the Tailwind compiler skipped generating `.bg-background` completely. This means that the Dialog overlay and content backgrounds are effectively transparent fallback rendering in the browser instead of the designated theme color.
